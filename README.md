# Trading Agent

Independent trading-agent project.

## Current scope
- Market-data analysis
- Technical indicators
- Signal generation
- Risk-management rules
- Paper-trading simulation
- Trade logging

> This project starts in paper-trading mode. Real-money execution is intentionally not enabled.

## Structure
- `src/` — agent logic
- `config/` — configuration
- `tests/` — tests
- `data/` — local sample data
