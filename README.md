# Trading Agent

Independent AI-assisted trading research and paper-trading agent.

## Agent pipeline
1. Market input
2. Signal ensemble
3. Market-regime detection
4. API-key-free RSS news context
5. Signal confidence
6. Risk engine (daily loss, drawdown, position limits)
7. Anomaly detection
8. Fee/slippage simulation
9. Paper decision
10. Audit trail

## Current scope
- Market-data analysis interfaces
- Signal generation and ensemble scoring
- Backtesting and walk-forward testing
- Risk management
- News/risk context from public RSS feeds
- Paper-trading simulation
- Decision audit trail
- Subscription access control
- Paper billing ledger

## Monetization model
- Basic: $9.99/month
- Pro: $24.99/month
- Advanced: $49.99/month
- Fee-based: no monthly subscription, with a simulated 2% platform fee
- 7-day trial configured
